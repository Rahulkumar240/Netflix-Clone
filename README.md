# Netflix Clone

A high-performance, responsive UI clone of the Netflix web application platform, built using **React** and **Vite**. This project focuses on component modularity, fluid layout transitions, and optimized frontend asset delivery.

## 🚀 Features

* **Authentic UI/UX:** Accurately replicates the modern Netflix streaming interface.
* **Responsive Layouts:** Designed to render across desktop, tablet, and mobile displays.
* **Optimized Asset Routing:** Custom Vite asset configurations to ensure lightning-fast media loading.
* **Modular Architecture:** Extensible component structure built for scale.

## 📂 Project Structure

```text
├── public/              # Static public assets
├── src/                 # Application source code
│   ├── components/      # Reusable UI elements (rows, navbar, banners)
│   └── main.jsx         # Application entry point
├── eslint.config.js     # Code quality and formatting configurations
├── index.html           # Main HTML shell
├── package.json         # Dependency manifest
└── vite.config.js       # Vite bundling engine configuration
```

## 🛠️ Installation & Setup

Get the application up and running locally by executing the following commands in your terminal:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd Netflix-Clone
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 🧰 Tech Stack

* **Frontend Framework:** React 18+
* **Build Tooling:** Vite
* **Linter:** ESLint
* **Styling Engine:** Custom CSS Modules
